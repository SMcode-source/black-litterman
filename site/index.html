Portfolio Optimisation

Black-Litterman

An interactive optimiser for S&P 500 equities and investment-grade credit, in one app. It starts from the returns the market already implies, then blends in your priors and your views — and solves the whole thing in your browser.

Open the optimiser → Source Yahoo Finance data, refreshed every weekday

What you control

Equities

S&P 500, live from Yahoo

The full index, with prices and market caps pulled from Yahoo Finance and the covariance estimated over several years of daily returns.

  • Pick your universe — all of it, the top 25/50/100 by size, or any subset
  • Set the prior — risk aversion and tau, or hand-edit the implied returns
  • State your views — absolute or relative, each with its own confidence
  • Constrain it — long-only, position caps, weights that sum to 100%
Credit

Investment-grade corporates

The same Bayesian core applied to a sample IG bond universe, with the credit analytics equities do not have.

  • Credit risk — expected loss, spread duration, DTS, Credit VaR
  • Spread-based covariance — OAS × duration, sector and rating correlation
  • Allocation — sector and rating breakdowns against the benchmark
  • Same controls — identical prior, view and constraint machinery

Bond-level analytics (OAS, spread duration, PD/LGD) are not available from Yahoo, so the credit side ships a curated sample universe rather than live market data.

A textbook Black-Litterman implementation inverts the N×N covariance, which at 485 names is roughly 108 operations and locks the tab. This one uses the view-space form of the posterior, so the only inverse is K×K where K is the number of views you wrote — usually two or three. The optimiser then needs nothing but matrix-vector products. Correctness is checked on every deploy against the freshly fetched data, including a reverse-optimisation round trip that must return the benchmark exactly.

Also in the repository

The original Python pipeline

The equity model started as a batch Python program, and that version is still here. It runs the same method offline over the full index and writes CSVs plus a matplotlib summary chart.

Runs locally — it writes files rather than serving a page. cd equity pip install -r requirements.txt python main.py

The credit app also has a FastAPI backend in app/backend/ that adds a cvxpy solver and Monte Carlo Credit VaR/CVaR. It is not part of the hosted site — GitHub Pages is static — but you can run it alongside the app locally.
