Credit Optimiser

Black-Litterman for investment-grade corporate bonds, with credit-specific risk analytics layered on top of the return model.

  • Views — absolute and relative, with per-view confidence
  • Constraints — issuer limits, position sizing, tracking error
  • Credit risk — expected loss, spread duration, DTS, Credit VaR
  • Allocation — sector and rating breakdowns vs benchmark
Open the app → Source

Runs entirely in your browser — no server, no data leaves the page. Credit VaR is computed parametrically at 99%. The full Python backend adds a cvxpy solver, Monte Carlo VaR/CVaR, and bond-file upload; run it locally to enable those.

S&P 500 Equity Model

A batch pipeline covering the full S&P 500: it fetches prices and market caps, derives equilibrium returns, applies views, and optimises with position constraints.

  • Universe — ~500 constituents via Yahoo Finance, no API key
  • Prior — reverse optimisation from market-cap weights
  • Views — top quartile by implied return, adjusted upward 20%
  • Limits — long-only, 10% maximum per position
Source
Runs locally — it writes CSVs and a matplotlib chart, so there is nothing to serve here. cd equity pip install -r requirements.txt python main.py

First run fetches all constituents (roughly 5–10 minutes), then caches the data so later runs are instant.
